# 📝 Blog Website (Django)

A full-featured **Blog Web Application** built using **Django**. This
project allows users to create, read, update, and delete blog posts with
image support and categorized content.

------------------------------------------------------------------------

## 🚀 Features

-   ✍️ Create, edit, and delete blog posts\
-   🖼️ Upload and display images in posts\
-   📂 Categorized blog sections\
-   🔍 Browse and view blog content\
-   🗃️ SQLite database integration\
-   🌐 Deployment-ready (Vercel config included)

------------------------------------------------------------------------

## 🛠️ Tech Stack

-   Backend: Django (Python)
-   Frontend: HTML, CSS (Django Templates)
-   Database: SQLite
-   Deployment: Vercel

------------------------------------------------------------------------

## ⚙️ Installation & Setup

``` bash
git clone https://github.com/your-username/blog_web_site.git
cd blog_web_site
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
